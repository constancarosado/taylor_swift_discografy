# Taylor Swift Discografy Site
Projeto desenvolvido no âmbito da cadeira de Bases de Dados, focado na recolha, limpeza, organização e estruturação de dados relacionados com a discografia da Taylor Swift. Após o tratamento dos dados, foi desenvolvido um website interativo para apresentar os álbuns, músicas e outras informações da artista de forma visual e organizada.
## Como Executar o Projeto Localmente

### Pré-requisito
Certifica-te de que tens o **[Python](https://www.python.org/)** instalado no teu computador. 

### Passo a Passo

1. **Abre a pasta** do projeto (onde se encontra o ficheiro `server.py`) no Explorador de Ficheiros do Windows, neste caso, a pasta será taylor_swift_discografy-main.
2. Na barra de endereço do explorador, apaga o texto, escreve **`cmd`** e prime **Enter**. Isto vai abrir o terminal diretamente nessa localização.
3. No terminal que abrir, escreve o seguinte comando e prime **Enter**:
   ```bash
   python server.py
O servidor vai iniciar e irá aparecer um link no terminal (normalmente http://127.0.0.1:5000/). Basta fazeres Ctrl + Clique nesse link e o site vai abrir automaticamente no teu navegador web.
